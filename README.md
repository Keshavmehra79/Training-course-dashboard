
# Training Course Dashboard

A simple responsive course dashboard built with React and Tailwind CSS.

## Features

- Display courses with title, category and progress
- Search courses by title
- Filter courses by category
- View course details
- Mark courses as completed
- Show an empty state when no courses match
- Responsive layout for desktop and mobile

## Technologies Used

- React.js
- Vite
- Tailwind CSS
- JavaScript

## Installation

1. Install Node.js.
2. Open the project folder in the terminal.
3. Run:

   npm install

4. Start the application:

   npm run dev

5. Open the local URL shown in the terminal.

## Project Structure

- data/courses.js: Sample course data
- components/CourseCard.jsx: Individual course card
- components/CourseList.jsx: List of courses
- components/CourseDetails.jsx: Selected course details
- App.jsx: State, search and filtering logic
